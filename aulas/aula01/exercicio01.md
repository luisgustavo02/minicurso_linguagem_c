## Questão 01

Construa um código que receba as seguintes informações do usuário:

- Idade
- Peso (em $\mathrm{kg}$)
- Altura (em $\mathrm{cm}$)

Com esses dados, calcule o IMC do usuário, dado pela fórmula:

$\mathbf{IMC} = \frac{\mathrm{peso}}{\mathrm{altura}} \, [\frac{\mathrm{kg}}{\mathrm{m}^{2}}]$

---

## Questão 02

Faça uma calculadora em linguagem C. O programa deve receber dois números e exibir as 4 operações básicas do primeiro pelo segundo. Exemplos:

**Entrada 1:**
```
12
4
```

**Saída 1:**
```
Digite um numero:
Digite outro numero:
12.00 + 4.00 = 16.00
12.00 - 4.00 = 8.00
12.00 * 4.00 = 48.00
12.00 / 4.00 = 3.00
```
