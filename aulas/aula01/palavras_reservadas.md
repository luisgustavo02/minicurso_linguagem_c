# Palavras Reservadas

As palavras reservadas são comandos padrões da linguagem de programação, usadas exclusivamente para essas funcionalidades. São elas:

**Comandos relacionados a variáveis**

- `char`
- `const`
- `double`
- `enum`
- `extern`
- `float`
- `int`
- `long`
- `signed`
- `static`
- `struct`
- `unsigned`
- `void`
- `volatile`

**Estruturas e blocos de comando**

- `break`
- `case`
- `continue`
- `default`
- `do`
- `else`
- `for`
- `if`
- `switch`
- `while`

**Outros comandos**

- `asm`
- `auto`
- `goto`
- `register`
- `sizeof`
- `typedef`
- `union`
